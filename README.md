# Shreyas Adyanthaya — portfolio

A static portfolio for GitHub Pages. Open `index.html` or serve this folder with any static web server. There are no packages to install and no build step.

## Updating content

- Edit the project descriptions, destination links, experience, dates and contact information in `index.html`.
- Replace `assets/superstore.png`, `assets/stocks.png` and `assets/zomato.png` with updated previews. Keep the filenames, update each image's width/height and alt text if needed, and the page will use the new files automatically.
- The current previews are the existing public project screenshots, not AI-generated dashboards. Their source images are 800 × 239 and intentionally provisional.
- Colors, spacing and typography are in `style.css`. The main display font is self-hosted Libre Caslon Text, included under the license in `assets/LibreCaslon-LICENSE.txt`.
- `script.js` adds keyboard-accessible project tabs. With JavaScript disabled, all three projects stay visible.

## GitHub Pages

The folder contents can be placed at the root of `shreyas7019/shreyas7019.github.io`. Keep `assets/`, `.nojekyll`, `index.html`, `style.css` and `script.js` together. Do not upload the surrounding workspace or generated design exploration files.

This local package has not been published. Review the working page before replacing the live site.

## Checks performed

Browser checks covered project selection with mouse and keyboard, loading the three real images, safe new-tab links, and horizontal overflow at 320, 390, 615, 1280 and 1440 pixels. Full-page desktop and mobile screenshots were reviewed. JavaScript syntax and the local HTTP response were checked. This is not a formal accessibility certification or a verification of external project-page availability.
